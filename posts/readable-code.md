## 見出しを構造として使う

ページタイトルをh1、本文の大きな見出しをh2、その下をh3にします。

### サイズだけで選ばない

見出しは文章の階層を表します。文字の大きさだけで選ばないようにします。

## コードの色分け

言語名を指定したコードブロックを使います。

```js
const message = "Hello, Markdown!";
console.log(message);
```

```css
.card {
  padding: 24px;
  border-radius: 16px;
}
```

## スマートフォンでの表示

長いコードは、コードブロック内で横スクロールできるようにします。
ページ全体が横にはみ出さないことを確認します。
